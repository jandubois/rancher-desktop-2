## Executive Summary

The head commit translates Windows host paths in `nerdctl build` and `builder debug`, and its handlers match nerdctl v2.1.2 and buildctl v0.21.1 for every unquoted form. Three things need fixing. Two new BATS tests fail the required Ubuntu bats-app job, because buildctl cannot set file owners on the guest's host mount. A `--file` that names a directory, `sub/` or `.`, loses its trailing slash. A quoted `type=` field turns stdout or an env secret's name into a path.

I2. **A `--file` that names a directory loses its trailing slash** — `rdd/pkg/nerdctlstub/overlay.go:47-48` [Claude Opus 5.5]

```go
		"--file":          fileOrURLOrStdinArg,
		"-f":              fileOrURLOrStdinArg,
```

nerdctl v2.1.2 splits `--file` with `filepath.Split`, and `buildkitutil.BuildKitFile` reads an empty or `.` file name as `Dockerfile`. On Windows the guest runs nerdctl in the translated working directory (`cmd/rdd/limavm_shell.go:83-91`), so before this commit `-f sub/` and `-f .` reached nerdctl unchanged and built `sub/Dockerfile` and `./Dockerfile`. Now `TranslateHostPath` cleans them to `/mnt/c/w/sub` and `/mnt/c/w`, nerdctl takes the directory for the Dockerfile, and the build fails.

The patch restores the suffix in `filePathArgHandler`. `builder debug --file` goes through it, and so does #1119's `cp`, where `src/.` means the directory's contents. `TranslateHostPath` also computes the guest's working directory, and its tests pin the cleaned form, so the patch leaves it alone.

I3. **A quoted `type=` field turns stdout and an env secret's name into paths** — `rdd/pkg/nerdctlstub/translate.go:219` [Codex GPT 6 Astra]

```go
	parts := strings.Split(arg, ",")
```

buildctl v0.21.1 decodes the values of `--output`, `--secret`, `--import-cache` and `--export-cache` as CSV (`csvvalue.Fields` in `cmd/buildctl/build/`). The stub splits at commas and keeps the quote in the key, so it never finds the `type` in `"type=tar",dest=-`. `streamsToStdout` then reports a file, and `dest=-` becomes a file named `-` in the working directory. In `"type=env",id=s,src=MY_TOKEN` the variable name becomes a path. Before this commit both values passed through, and buildctl streamed the tar to stdout and read the variable. Nobody needs to quote a `type=` field, so the trigger is rare. But decoding the CSV also lets a quoted path keep its comma, which `nerdctl.md` lists as unsupported. The probe runs on macOS, so its relative paths resolve against the probe's directory.

S1. **`builder debug` translation cannot run in the guest** — `rdd/pkg/nerdctlstub/overlay.go:56-61` [Claude Opus 5.5, Gemini 3.5 Flash]

```go
	"builder debug": {
		"--file":   filePathArg,
		"-f":       filePathArg,
		"--secret": builderCacheArg,
		"--ssh":    sshArg,
	},
```
