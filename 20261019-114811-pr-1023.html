Concerns ¶

  • (in-scope) Any config.json that rdd can't read or parse holds Settled at False under front and back. Round 3 raised the parse case. I2's probe shows the I/O case too. An unreadable config.json sets Failed while the startup block is written, and app_controller.go:721-722 gates on it. At the merge-base front never read the file, so rdd set --wait now waits on a plugin registration the user may not need. Options: give the plugin edit its own reason, or stop gating Settled on plugin-edit failures. Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.5 Flash
  • (in-scope) App users still can't reach the plugin registration. No code under pkg/rancher-desktop writes application.addPath, so app installs run manual. Codex GPT 6 Astra Claude Opus 5.5 Gemini 3.5 Flash
  • (future) rdd svc delete unwinds with the CLI's DOCKER_CONFIG, not the daemon's. Codex GPT 6 Astra Claude Opus 5.5 Gemini 3.5 Flash
  • (future) The shutdown clear can outlast the manager's 10 s grace period, since lockTimeout is 30 s (pkg/service/controllers/manager.go:153, dockerconfig.go:29). Codex GPT 6 Astra Claude Opus 5.5 Gemini 3.5 Flash

Strengths ¶

  • (in-scope) Edit holds the lock from load through save. A two-process probe showed one writer timing out while another process held the lock, and a later writer adding the plugin directory without losing currentContext. Codex GPT 6 Astra
