## Review Process Notes

### Skill improvements

- Before launching agents on a PR that a project plan or decision memory tracks, grep the whole project memory directory, plans included, for the PR's number and its changed files, and inline every recorded design ruling on that code as a do-not-re-suggest note. Agents cannot see those rulings, so they re-derive the rejected alternative, and a consolidation-time grep of the top memory index misses a ruling kept in a linked plan.

### Repo context updates

- [repo] Every renderer window that loads the Vuex store sends its own `backend/app-status-changed` report on each change to the App, so a main-process handler runs once per window per change and must be idempotent. A report lacks a condition when the window has not listed the App yet, when a watcher restart committed an empty list, when the controller that owns the condition has not written it, or when the App was deleted. Treat a missing condition as unknown. Only an explicit False or Unknown status means stopped.
