Executive Summary ¶

The PR serves \\.\pipe\docker_engine through a proxy built on httputil.ReverseProxy. The proxy rewrites drive-absolute bind sources in POST /containers/create to /mnt/<drive> paths, and the shared path helpers now translate \\?\C:\ paths too. The relay switch broke one thing. An empty create request panics the proxy's handler, so the client gets EOF instead of dockerd's 400. And the suite doesn't pin DisableKeepAlives, which keeps backend connections from outliving Serve. Both come with patches and tests.

Acknowledged Limitations ¶

Round 1's limitations still hold, checked against the code:

  • containers_create_body.go:20-28: a host path in a field that a newer API version adds goes through untranslated.
  • containers_create_body.go:84-93: a body that repeats a key in different case goes through untranslated.
  • containers_create.go:21-23: relative paths and rooted paths such as /var/run/docker.sock stay untranslated.

Declined in prior rounds:

  • The backend dial waits for Hyper-V's own timeout (hostswitch_windows.go:190-192), declined Round 1. It is inherited from the merge-base HostBridge, and the fix belongs in socketbridge.DialVsock for both bridges. It is tracked.
  • No direct CutVolumeSource table test and no forward-slash source in TestMungeContainersCreateMounts, declined Round 1 as optional. cbdcd73e4 has since added TestCutVolumeSource.
  • Hijacked connections outlive Serve's shutdown, declined Round 1 as future work; the merge-base bridge also left connections open.
  • Attach and exec without an Upgrade header lose stdin, declined Round 1 as future work; the Docker CLI sends Upgrade: tcp, and RD1 has the same gap.
  • The Docker pipe name is global, declined Round 1 as pre-existing.
  • The pipe gets go-winio's default security descriptor, declined Round 1 as pre-existing.

Do not re-suggest:

  • Replacing string(bytes.TrimSpace(...)) == "null" in findKey to save an allocation; it doesn't allocate.
  • Deriving startProxy's context from t.Context(); its cleanup already cancels it.
  • Making pathRoot handle an extended-length UNC working directory (\\?\UNC\server\share). It returns //?/UNC there, so \data becomes //?/UNC/data, but pathRoot predates this PR, and the guest mounts neither that path nor //?/UNC/server/share/data.
