Executive Summary ¶

The PR moves each mirror-name prefix onto the API type it names and makes api.MirrorName generic over that type, so a caller can no longer pair a resource with another type's prefix. Every prefix and hash input matches the merge-base, so stored mirror names don't change. This round converged. Nothing needs fixing before merge, and the three suggestions below are optional cleanups.

S3. The "extra arguments are separated" test passes without the separator Claude Opus 5.5 Codex GPT 6 Astra¶
rdd/pkg/util/api/mirror_name_test.go
		withExtra := api.MirrorName[*mockMirrorName]("invalid_name", "extra1", "extra2")
		assert.Assert(t, withoutExtra != withExtra)
	})

	t.Run("extra arguments are separated", func(t *testing.T) {
		one := api.MirrorName[*mockMirrorName]("aaabbb", "ccc")
		two := api.MirrorName[*mockMirrorName]("aaa", "bbbccc")
		assert.Assert(t, one != two, "%s <-> %s", one, two)
	})
}

aaabbb and aaa are valid DNS-1123 names, so MirrorName returns them unchanged and never hashes the extras. The assertion therefore compares "aaabbb" with "aaa", and it passes whatever the hashing does. These lines predate the PR (753e0641d1), but the PR rewrites both calls, so this is the cheap place to fix them.

I removed the \x00 separator at rdd/pkg/util/api/mirror_name.go:52, and the test still passed. With inputs that need hashing, AAAbbb and AAA, the same mutation fails it (one is two: zz-79e38…), and the real code passes.

	}

Design Observations ¶

Concerns ¶

  • Nothing enforces the nil-receiver rule (future) Claude Opus 5.5 Gemini 3.5 Flash. MirrorName calls MirrorPrefix() on a zero T (rdd/pkg/util/api/mirror_name.go:36-37). api.MirrorName[api.MirrorNameType]("My_Vol") compiles and panics with a nil dereference, and a pointer type whose MirrorPrefix has a value receiver would panic the same way. No caller does either today. Claude proposed func MirrorName[E any, T interface{ *E; MirrorNameType }] with T(new(E)).MirrorPrefix(), so callers write api.MirrorName[containersv1alpha1.Volume](…) and T is inferred. My probe confirmed that form returns the same name as today and rejects the interface type argument at compile time.
  • client.Object in the constraint is more than MirrorName uses (future) Claude Opus 5.5 Gemini 3.5 Flash. It gives pkg/util/api its first controller-runtime import and makes the test type embed a ConfigMap. It also restricts the helper to API objects, which may be the point.

Strengths ¶

  • Each prefix is on the type it names (in-scope) Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.1 Pro Gemini 3.5 Flash. The "cns" literals in two webhooks and the mock controller are gone, and so is composeMirrorName, the constant PR #831's author wanted to fix.
  • No mirror name changes (in-scope) Claude Opus 5.5 Codex GPT 6 Astra. Every call site keeps its hash inputs, including (ev.ID, e.Namespace) for containerd containers, (id, tag) for Docker images, and the ns\x00name join for containerd images, so mirrors a previous build stored keep their names.
