I2. **`network-setup.service` recommends a drop-in override that has no effect** — `rdd/overlay/root/usr/local/lib/systemd/system/network-setup.service:11-19` [Codex GPT 6 Astra] (round 1 I2, unaddressed)

```ini
# A systemd drop-in can set this to add network-setup flags without
# replacing the ExecStart below. Empty by default; the unquoted
# $NETWORK_SETUP_EXTRA_ARGS splits on whitespace into separate arguments.
Environment=NETWORK_SETUP_EXTRA_ARGS=
# Rancher Desktop passes the VM_SWITCH_LOG and NETWORK_SETUP_EXTRA_ARGS
# through this file, which is written per instance.
# Read after the defaults above so those values win and the
# `-` prefix allows to make EnvironmentFile optional.
EnvironmentFile=-/etc/sysconfig/rancher-desktop
```

systemd merges `EnvironmentFile=` values after every `Environment=`, drop-ins included. In v255, `src/core/exec-invoke.c` passes `context->environment` to `strv_env_merge` ahead of `params->files_env`, and `src/core/execute.c` merges the files in the order listed. Rancher Desktop always writes `NETWORK_SETUP_EXTRA_ARGS` to the file, even as `""`. So a drop-in that sets it with `Environment=`, as lines 11-12 suggest, is silently ignored (probe case 2). Lines 17-18 credit line order, but case 3 moves `EnvironmentFile=` above the defaults and the file still wins.

Codex rated this a Suggestion, since a drop-in can add a later `EnvironmentFile=`. Case 4 confirms that route works. But the comment tells readers to set the variable, and a reader who follows it finds the flag silently ignored, so the finding stays Important. The fix names the route that works.

```bash repro
# Save as probe-envfile.sh; run as root on a throwaway systemd Linux host:
#   sudo bash probe-envfile.sh
# Models network-setup.service: Environment= defaults in the unit, an optional
# EnvironmentFile=, and an operator drop-in setting NETWORK_SETUP_EXTRA_ARGS.
set -o errexit -o nounset
U=/run/systemd/system/envprobe.service
F=/run/envprobe.env
cat >/run/envprobe-args.sh <<'EOF'
#!/bin/sh
out=""; for a in "$@"; do out="$out<$a>"; done; echo "argv=$out"
EOF
unit() { # $1: "defaults-first" or "file-first"
  {
    echo "[Service]"; echo "Type=oneshot"
    [ "$1" = file-first ] && echo "EnvironmentFile=-$F"
    echo "Environment=VM_SWITCH_LOG=/var/log/vm-switch.log"
    echo "Environment=NETWORK_SETUP_EXTRA_ARGS="
    [ "$1" = defaults-first ] && echo "EnvironmentFile=-$F"
    echo 'ExecStart=/bin/sh /run/envprobe-args.sh --vm-switch-logfile ${VM_SWITCH_LOG} $NETWORK_SETUP_EXTRA_ARGS'
  } >"$U"
}
run() { systemctl daemon-reload; systemctl start envprobe.service
        journalctl --unit=envprobe.service --output=cat | grep argv | tail -n 1; }
dropin() { mkdir -p "$U.d"; printf '[Service]\nEnvironment=NETWORK_SETUP_EXTRA_ARGS=--from-dropin\n' >"$U.d/extra.conf"; }

echo "1. drop-in, no EnvironmentFile:";              unit defaults-first; rm -f "$F"; dropin; run
echo "2. drop-in, file with NETWORK_SETUP_EXTRA_ARGS=\"\":"; printf 'NETWORK_SETUP_EXTRA_ARGS=""\n' >"$F"; run
echo "3. EnvironmentFile= line placed before the defaults:"; rm -rf "$U.d"; unit file-first
printf 'VM_SWITCH_LOG="/mnt/c/Users/Jan Doe/vm-switch.log"\nNETWORK_SETUP_EXTRA_ARGS="--vm-switch-logfile-append --trace-packets"\n' >"$F"; run
echo "4. drop-in adding a second EnvironmentFile=:";  unit defaults-first; printf 'NETWORK_SETUP_EXTRA_ARGS=""\n' >"$F"
mkdir -p "$U.d"; printf 'NETWORK_SETUP_EXTRA_ARGS=--from-second-file\n' >/run/envprobe2.env
printf '[Service]\nEnvironmentFile=/run/envprobe2.env\n' >"$U.d/extra.conf"; run
rm -rf "$U" "$U.d" "$F" /run/envprobe2.env /run/envprobe-args.sh; systemctl daemon-reload
```
