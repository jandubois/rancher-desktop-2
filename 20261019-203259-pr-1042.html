Executive Summary ¶

The PR turns the Container Engine preferences page back on and adds a currentNamespace getter that falls back to default when nothing is selected. But nothing restarts the resource watches when that fallback changes, so the namespace picker can name one namespace while the list shows another, or all of them. Separately, the Volumes page never watches namespaces, so its picker stays empty on a direct visit, and the PR closes #970, which asks for exactly that.
