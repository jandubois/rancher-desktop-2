// so we convert it to WSL2 supported path. On other platforms the path is returned unchanged.
func toLinuxPath(hostPath string) string {
	if goruntime.GOOS != "windows" {
		return hostPath
	}
	if len(hostPath) >= 2 && hostPath[1] == ':' {
		drive := strings.ToLower(string(hostPath[0]))
		rest := strings.ReplaceAll(hostPath[2:], `\`, `/`)
		// /mnt/ is the mount point for drvfs disks in WSL2, per the default
		// value of `[automount] root=` in `/etc/wsl.conf`.
		return "/mnt/" + drive + rest
	}
	return hostPath
}

// Reconcile implements a singleton app reconciliation loop.
// The app controller is a cluster-scoped singleton - only one instance named 'app' is allowed.

TranslateHostPath is a second implementation of that mapping, and guestDir (limavm_shell.go:154-159) repeats toLinuxPath's GOOS check. Whoever changes the mount root, for example with a root= line under [automount] in rdd/overlay/root/etc/wsl.conf, has to find both.

func ChildExit(err error) *Error {
	exitErr, ok := errors.AsType[*exec.ExitError](err)
	if !ok {
		return nil
	}
	// A signal-killed child has no exit code. ExitCode() returns -1, which
	// os.Exit maps to 255 rather than the shell's 128+signal.
	return &Error{Code: exitErr.ExitCode()}
}

The *exec.ExitError holds a syscall.WaitStatus that records the signal; Windows has the type too, with Signaled() always false. The comment at run.go:172-173 credits signal handling with the 128+signal behaviour, but the wait status is what records the signal.

Acknowledged Limitations ¶

  • UNC and \\?\ working directories get only their backslashes turned into slashes (hostpath.go:32-35). The guest cd fails and the shell falls back to the home directory. Do not re-flag.

Review Process Notes ¶

Repo context updates

  • [repo] Windows host paths appear in the WSL2 guest under /mnt/<drive>/, WSL's default automount root, which the distro's /etc/wsl.conf leaves unchanged. The app controller already maps host paths this way for its template parameters. Flag new code that maps a Windows path to its guest path by hand instead of reusing an existing translator, because a second copy has to change with the mount root too.
  • [repo] UPDATE the is_windows/is_msys entry: host_path itself calls cygpath whenever is_windows holds, so a test that calls host_path behind skip_on_unix follows the settled pattern, and its failure under a WSL-hosted bats is the helper's latent limitation. Do not flag such a test.
  • [repo] Lima's store functions find instances through LIMA_HOME, read on every call, with ~/.lima as the fallback. Only the lima controller's registration and the CLI command that opens a guest shell set it. Flag code that calls a Lima store function, directly or through a helper package, in a process that may run without the lima controller: a standalone cmd/*-controller binary or a --controllers subset.
