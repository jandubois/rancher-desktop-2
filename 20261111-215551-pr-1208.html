This round fixes the arm64 deb's qemu dependency and adds the firmware Requires, and the fork's OBS indexes show the right dependencies on every distro. The split OBS jobs bring a new failure: trigger-obs runs whenever its needs are skipped, because needs.* in a job's if: also covers ancestor jobs. Design Observations ¶

Concerns ¶

  • The OBS cutover still lives only in the PR body (in-scope) Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.1 Pro Gemini 3.5 Flash. The spec's Source0 is now %{name}.%{RD_ARCH}.zip and the S3 keys have new names, so each RD2 package's _service must change once the branch or tag it builds from contains this PR. linux-release-process.md and release-checklist.md still don't give a step for it. trigger-obs only starts the service run, so GitHub stays green while OBS fails to fetch its sources.
