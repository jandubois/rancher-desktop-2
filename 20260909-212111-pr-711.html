// serve starts a server that writes one byte every gap and never finishes, or,
// when gap is zero, sends the headers and then goes silent.
func serve(t *testing.T, gap time.Duration) string {
	done := make(chan struct{})
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		w.(http.Flusher).Flush()
		for {
			if gap > 0 {
				_, _ = w.Write([]byte("x"))
				w.(http.Flusher).Flush()
			}
			select {
			case <-r.Context().Done():
				return
			case <-done:
				return
			case <-time.After(max(gap, 10*time.Millisecond)):
			}
		}
	}))
	t.Cleanup(srv.Close)
	t.Cleanup(func() { close(done) })
	return srv.URL + "/distro.raw.xz"
}

// stage runs Stage in the background and reports whether it returned within
// patience, plus the error it gave.
func stage(t *testing.T, ctx context.Context, url string) (time.Duration, error, bool) {
	sum := sha256.Sum256([]byte("never served"))
	dep := Dependency{Name: "distro", Version: "0.2.7", Asset: Asset{
		Platform: "linux", Arch: "arm64", Variant: "raw",
		URL: url, Checksum: "sha256:" + hex.EncodeToString(sum[:]),
	}}
	dir := t.TempDir()
	s := &Stager{CacheDir: filepath.Join(dir, "cache")}
	done := make(chan error, 1)
	start := time.Now()
	go func() { done <- s.Stage(ctx, dep, filepath.Join(dir, "embedded", "distro.raw.xz")) }()
	select {
	case err := <-done:
		return time.Since(start), err, true
	case <-time.After(4 * time.Second):
		return time.Since(start), nil, false
	}
}

func (m Manifest) Select(name string, sel Selector) (Dependency, error) {
	entry, ok := m[name]

}

Design Observations ¶

Concerns ¶

  • Concurrent builds do not share the cache (future) Claude Opus 5. Eight stagers over one cache directory made eight separate downloads in my probe, all succeeding, with the right checksum at the destination and no leaked temporary files. The goal at lines 71-73, one copy per asset across bats worktrees, holds for sequential builds. Two parallel worktrees pull 434 MB. Round 1 declined a lock file on this path, so this is a property to know rather than a fix to make.
  • Prune's foreign-file heuristic now guards a directory the tool owns (in-scope). Review Process Notes ¶

Skill improvements ¶

  • When a round's fix narrows a prior finding's guarantee, decide whether the residual failure is the same server or system behaviour the finding named, or a neighbouring one. A fix that closes the named case documents its own reduced scope in a comment and is settled; a neighbouring behaviour producing the same user-visible failure is a new finding, judged fresh at whatever severity the evidence supports. Say in the finding which of the two you decided, so the author can see the call rather than the conclusion.
  • Before accepting a finding that traces a value into a dangerous sink, find where the value is assigned, not where the struct field is declared. A constructor that copies a caller's argument into a field of the same name looks identical, in the sink's neighbourhood, to one that copies attacker- controlled data, and the difference decides the severity.
  • Where a finding is that code is untested, prove it by deleting the mechanism and running the suite, and include one mutation the suite does catch. A coverage percentage names a line count; a surviving mutation names a behaviour nobody would notice losing, and the caught control shows the suite was capable of noticing.

Repo context updates ¶

  • [repo] os.UserCacheDir() on Windows is %LocalAppData%, which is also the parent of instance.Dir() (rdd/pkg/instance/instance.go), and rdd svc delete ends in os.RemoveAll(instance.Dir()). Any Go code choosing a cache or state directory under os.UserCacheDir() on Windows therefore shares a tree with the daemon instance and is removed with it. Bats runs set RDD_INSTANCE, so only the default instance collides. On macOS and Linux the same parent is the Electron app's own cache, set from pkg/rancher-desktop/utils/paths.ts.
  • [repo] rdd/dependencies.yaml is the guest dependency manifest that yarn rddepman guest regenerates. Manifest.Select takes the dependency name from its caller and copies it into Dependency.Name; the manifest's own map keys never reach a filesystem path. Findings that trace a manifest key into filepath.Join need a caller that passes one.
  • [repo] The progressInterval constant, and httpClient's package-init read of stallTimeout, are the reason logProgress and ResponseHeaderTimeout have no tests in rdd/pkg/guestdeps. Sibling knobs in the same file are variables with comments saying tests shorten them.
