Design Observations ¶

Concerns ¶

  • (in-scope) On a namespaced page, the first list of containers, images or volumes goes out unfiltered, because currentNamespace is undefined until namespaces loads (container-engine.ts:83). The namespace load then changes the getter, and the plugin rewatches while those lists are usually still in flight, which is the window I1 leaks. The merge-base kept the unfiltered rows until the user picked a namespace, so this PR shortens the flash. Holding the namespaced watches until the namespace list loads would remove both the flash and the rewatch. Claude Opus 5.5 Gemini 3.1 Pro Codex GPT 6 Astra Gemini 3.5 Flash
  • (future) A re-created namespace takes the view back without the user asking. selectedNamespace keeps its value after the deletion, and the getter returns it again once the namespace exists (container-engine.ts:80). Clearing the selection when the getter falls back would end that. Gemini 3.1 Pro Gemini 3.5 Flash Codex GPT 6 Astra Claude Opus 5.5
  • (future) With browsing disabled (Volumes.vue:149), nothing in the UI reaches /volumes/files/:name, whose page still maps the removed initialPreferences (pages/volumes/files/_name.vue:167). 'should browse volume files' will fail once its fixme suite returns. Codex GPT 6 Astra Claude Opus 5.5 Gemini 3.5 Flash

Strengths ¶

  • The spec now builds its store from the module's own plugins (container-engine.spec.ts:129), the list that entry/store.ts:49 collects, so removing the plugin fails the test. Codex GPT 6 Astra Claude Opus 5.5

Review Process Notes ¶

Skill improvements ¶

  • When staging installed dependencies for agents from the main checkout, compare the staged versions of the packages that the reviewed manifest pins against that manifest before launching, and install into the stage when they differ. A checkout's node_modules lags its own branch after a rebase or a dependency bump, and every agent's test run then exercises other versions without saying so.

Repo context updates ¶

  • [repo] In this repository, eslint run with node_modules symlinked into a worktree reports import-x/order errors in files that pass CI, untouched files included. Before reporting an import-order or other import-resolution finding, lint with a real install (yarn install --immutable --mode=skip-build) or compare against the same run on an untouched file.
  • [repo] A renderer watch stream (pkg/rdd-client/watch.ts) does not send timeoutSeconds and clears its client timeout once the connection opens, and rdd does not set MinRequestTimeout, so the apiserver ends a quiet watch only after MinRequestTimeout (1800 s by default) times a random factor in [1, 2), which is 30 to 60 minutes. Size a leaked renderer watch by that lifetime, not by the next event.
