So a delete callback sees string dates where add and update callbacks see Dates. The one registered callback ignores its argument (pkg/rancher-desktop/store/rddConnection.ts:582), so nothing reads the difference today. Claude Opus 5.5 Codex GPT 6 Astra
  • (future) getSerializationType now names rdd's own models, so KubernetesObjectApi's create, patch and replace serialize rdd kinds through the model's attribute map (pkg/rdd-client/object.ts:123-129). That drops any field the generated model does not declare. Nothing in the app calls KubernetesObjectApi, so only a future caller would meet this. Codex GPT 6 Astra Claude Opus 5.5

Review Process Notes ¶

Skill improvements ¶

  • When an agent's stderr reports a quota reset that falls after the pass deadline, stop the agent and drop it at once. The CLI otherwise sleeps until the reset, and the liveness monitor needs a full stall interval to notice.

Repo context updates ¶

  • [repo] The rdd-client cache holds objects deserialized through the generated models in pkg/rdd-client/gen, for list items and watch events alike, and model deserialization drops every field that the generated model does not declare. Flag app code that reads a CRD field that the generated models lack, because the store holds undefined for it even though rdd sends the field.
