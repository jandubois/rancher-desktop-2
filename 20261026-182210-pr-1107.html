A standalone kube config holding only the `rancher-desktop-2` context is also written to `~/.rd2/kube.config`, which the [`rdd run`](cmd_app.md#rdd-run) command points `KUBECONFIG` at.

### Docker CLI plugins

The bundle ships Docker CLI plugins (`buildx`, `compose`, …) in a `docker-cli-plugins` directory beside its `bin` directory. Docker never discovers plugins via `PATH`. It searches the directories listed in `cliPluginsExtraDirs` in `~/.docker/config.json` first, then `~/.docker/cli-plugins`, then its system plugin directories. So the daemon mirrors the bundled plugins into a per-instance directory (`~/.rd2/docker-cli-plugins`) and registers that directory in `cliPluginsExtraDirs`.

This registration is driven by [`spec.application.addPath`](#app-object), the same setting that manages `PATH`: `front`/`back` add the directory (prepended or appended), and `manual` removes it. Because `config.json`'s array has no fence to mark our entry (just like the Windows `Path`), the controller keeps a separate marker file in the short directory so, under `manual`, it only removes an entry it added and leaves a user-added one alone. Both the engine controller (which edits `currentContext`) and this one serialize their `config.json` read-modify-writes behind a cross-process lock so neither drops the other's edit. Docker searches every `cliPluginsExtraDirs` entry before `~/.docker/cli-plugins`, so even under `back` our plugins win over the user's own copies there; `back` yields only to other tools' entries in `cliPluginsExtraDirs`.

Design Observations ¶

Concerns ¶

  • (in-scope) get-paths sends the renderer the whole Paths object, though the tab needs only bin_dir. #1049 proposed a handler in main/rdd-ctl.ts, next to rdd/kube-config, that returns only the bin directory. That handler would also be the one place for S3's override. Claude Opus 5.5
  • (future) The selector now reads and writes the store itself, so FirstRun can reuse it only by going through preferences/modify as well (S2). Gemini 3.1 Pro Gemini 3.5 Flash

Strengths ¶

  • Replacing the nested <label :for="name"> with a <span> fixes invalid markup; the outer <label> still handles the click, and aria-describedby now ties each radio to its description. Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.1 Pro Gemini 3.5 Flash
  • The options come from the generated AddPath enum, so they follow the CRD. Gemini 3.1 Pro
  • Writing through preferences/modify keeps the dialog's Apply and Cancel behaviour. Codex GPT 6 Astra Gemini 3.5 Flash
  • The e2e test's ~/.rd2/bin assertion tells the IPC value apart from the ~/.rd/bin placeholder, so it fails if the handler goes missing. Claude Opus 5.5

Testing Assessment ¶

  • I ran the full Jest suite in a worktree at the review SHA, with dependencies installed from the PR's own lockfile. 59 suites passed; mac-ca.spec.ts timed out while Electron downloaded its binary on first import, and passed when rerun alone. With the I1 and I2 patches applied, 60 suites passed and 1 was skipped (587 tests passed, 36 skipped).

Review Process Notes ¶

Skill improvements ¶

  • When staging installed dependencies for agents, also run the install steps that a package defers to its first import, such as a binary it downloads, before staging the tree. An install that skips build scripts leaves such a package to fetch on first use, so each agent's test run downloads it again, and a test that imports it can time out mid-download and read as a failure.

Repo context updates ¶

  • [repo] Changing an en-us.yaml string's text or placeholders leaves every other locale on its old translation, and the renderer's t prefers the selected locale's string, ignoring arguments that string lacks. Each locale key records the English it was translated from in a # @source comment. To see what a PR does to the locales, build src/go/i18n-report in its module directory, then run drift, stale and validate --locale=<code> from the repo root at the merge-base and at the head, and flag any key that the head adds. Check .github/workflows for an i18n-report check --locale step before assuming CI catches this.
  • [repo] A value returned through ipcMainProxy.handle crosses Electron's structured clone: own enumerable getters are evaluated and copied, but a Proxy throws "could not be cloned" and the renderer's invoke rejects. getPaths() returns such a Proxy when rdd service paths fails. Reject a fix that wraps an IPC return value in a Proxy.
  • [repo] A Preferences tab component may read preferences/preferences without optional chaining: pages/Preferences.vue renders the tabs only once the committed App spec has keys, and the CRD defaults each top-level spec section. Rate a missing-?. finding in such a component as latent unless it has a caller outside that page.
  • [repo] UPDATE the entry on pages/FirstRun.vue and addPath once the Environment tab writes application.addPath on the default branch: its claims that the tab is commented out and that no app code writes addPath then stop holding.
