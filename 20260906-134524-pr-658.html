## `rdd run`

`rdd run COMMAND [ARGS...]` runs a command against this Rancher Desktop instance without changing your selected contexts.

Review Process Notes ¶

Skill improvements ¶

  • Before launching, run in the lead worktree any verification whose cost scales with the number of commits or files (per-commit builds, a full test suite, a generated-file check), and state the results in the initial prompt with an instruction not to repeat them. Otherwise an agent handed a request to review each commit spends its whole deadline on builds the orchestrator can run once, and a watchdog kill leaves no output at all.
  • Run suites and lints from the lead worktree even when the main checkout is at the review SHA when you check. A concurrent session can switch the main checkout's branch mid-run, and the run then reports on a different tree with no error; copy gitignored build inputs into the lead worktree instead. This replaces the current "when the main checkout is clean and sits at the review SHA, run the suite from there".
  • Check the merge-base's version of a sentence before filing an intermediate-commit doc inconsistency as a commit-structure finding. Text that predates the series and that a later commit rewrites is inherited staleness, and a finding on it rates the recut for a defect the author did not write.
