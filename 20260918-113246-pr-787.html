### Name encoding

Where we mention encoding names into a `foo-0000...` form below, we use the
following algorithm:

- The general encoded form is a prefix (`foo` in this example), follow by a dash
  (`-`), followed by the SHA-256 hash of the input name, in lower-case
  hexadecimal.
- If the name is not a valid Kubernetes object name (DNS 1123 subdomain), then
  the name is encoded.
- If the name format matches the encoded form (prefix for the type, dash, and
  hash) with no other text before or after, then the name is encoded.
- Otherwise, the name is used directly.

// field returns the value of "  <key>:" nested under "<section>:", or of
// "<key>:" at top level when section is empty.
func field(block, section, key string) string {
	in := section == ""
	for _, line := range strings.Split(block, "\n") {
		switch {
		case line == section+":":
			in = true
		case in && strings.HasPrefix(line, "  "+key+":"):
			return strings.TrimSpace(strings.TrimPrefix(line, "  "+key+":"))
		case in && section != "" && line != "" && !strings.HasPrefix(line, " "):
			in = false
		case in && section == "" && strings.HasPrefix(line, key+":"):
			return strings.TrimSpace(strings.TrimPrefix(line, key+":"))
		}
	}
	return ""
}

func MirrorName(prefix, input string) string {
	needsEscape := len(validation.IsDNS1123Subdomain(input)) > 0
	if !needsEscape {

Design Observations ¶

Concerns ¶

  • The "one shared algorithm" framing holds for two of five kinds (future) Claude Opus 5. The new section opens "Where we mention encoding names into a foo-0000... form below, we use the following algorithm", but only ContainerNamespace and Volume route through api.MirrorName. Containers use containerdMirrorName, Images use imageMirrorNames and containerdImageMirrorName, and ComposeProject has no code. The two image helpers already agree with the shared algorithm by accident, since every input they hash contains a \x00 or a : and can never be a valid object name, so api.MirrorName("img", id+"\x00"+tag) returns the same bytes today. Converting them is mechanical and would delete two helpers.
  • The mock controller ships a third naming scheme (future) Claude Opus 5. sanitizeKubernetesObjectName at pkg/controllers/mock/image_reconciler.go:45-47 replaces / and : and nothing else, so a mock volume or image name with an underscore or an upper-case letter produces an invalid object name and the apply fails. The mock's namespace reconciler already calls api.MirrorName; its Volume and Image reconcilers do not. Pre-existing, found while tracing call sites.

Skill improvements ¶

  • When a PR's stated purpose is to fix a defect class named by a prior review, enumerate every helper in the repo that implements the same construction and check each one, not only those the diff touches. A fix applied to one member of a class and not its siblings is a finding the diff cannot show.
  • Before repeating a proposed fix that routes an existing helper through a shared one, check what the existing helper hashes that the shared one drops. Run the target's own test suite against the proposed fix: a test named for the property the fix breaks can still pass, because it was written to discriminate something else.
