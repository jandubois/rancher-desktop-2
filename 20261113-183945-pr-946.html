Design Observations ¶

Concerns ¶

  • The run key is still half migrated (in-scope). With the de-duplication gone, processState.resourceVersion only feeds the race checks at compose_process.go:145 and :158. Each reconciler has its own tracker (compose_controller.go:79, :88) and one worker, so neither check can fire. Meanwhile the up-request reconciler decides restarts by generation. Comparing the command itself, as the wait goroutine does at compose_process.go:172, would leave the generation as the only restart key. Claude Opus 5.5 Codex GPT 6 Astra
  • The temporary-directory fallback still exists once per OS, and relative --file paths still defeat it (in-scope, open question). Once status.workingDir is gone, down from a temporary directory still fails on the missing configs. The maintainers have not ruled on handling missing configs once, before the per-OS spawners. Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.5 Flash
  • docker comes from the daemon's PATH (future). compose_process.go:103 runs the first docker on the daemon's PATH, not the instance's bin directory. Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.5 Flash
  • nerdctl compose projects are never detected (future). Membership needs com.docker.compose.config-hash (compose_reconciler.go:420), and rdd/dependencies.yaml:56 pins nerdctl 2.1.2, which does not set it. Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.5 Flash
  • An owned ComposeUpRequest is never reaped (future). rdd's apiserver does not run a garbage collector, so a request whose owner is deleted first stays forever. One sentence in api_containers.md would warn the first client that sets an owner. Claude Opus 5.5

Strengths ¶

  • The spawn-failure path removes and re-adds Settled and Failed (compose_up_request_reconciler.go:152-155), the smallest change that gives a failed rerun a new LastTransitionTime. Claude Opus 5.5 Codex GPT 6 Astra
  • The Windows fallback matches Go's own check. With SysProcAttr nil, os.StartProcess stats Dir and reports a missing one as a *PathError whose Op is "chdir" (go1.27.3 os/exec_posix.go:30-35). Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.5 Flash
  • Pruning checks the Container objects themselves, so recovery no longer depends on a Container event that rdd lost, and the HasMembers=Unknown branch and the rescan share one routine. Codex GPT 6 Astra Claude Opus 5.5

Acknowledged Limitations ¶

Declined in prior rounds ¶

  • Linux kill fails with EINVAL on kernels before 6.9 — declined Round 2: "6.9 is older than anything reasonable at this point." The comment at command_linux.go:101-103 states that floor.
  • No test pins the passing of spec.env — declined Round 2: extensions will exercise it.
  • The finalizer string is defined twice — declined Round 2: "Ignoring for now." It is still at compose_utils.go:23 and engine_reconciler.go:42.
  • BATS convention deviations — declined Round 2: the compose_project_name captures, the sleep 2 before a negative check, and the explanatory echo stay. The local split is fixed.
  • Blocking fake commands outlive their subtests — declined Round 2. The subtest that round 2 cited is gone.

Other limitations ¶

  • nerdctl: compose_process.go:102 says "TODO: Support nerdctl here." On containerd, deleting a project runs docker compose down, which fails, and the Container fallback finishes the deletion; up settles as Failed.
  • Windows job assignment: command_windows.go:21-29 assigns the process to its job only after it starts. Do not re-suggest assignment at creation without a measured exit inside that window.
  • Docker discovery: compose-docker.bats:22-25 skips the suite when the compose plugin is missing; CI ran it on all three platforms.
  • down may run again while members are still being removed (compose_reconciler.go:281-287). For a member whose Container is already gone, it reruns every second until the rescan (S1).
  • Do not re-suggest: stripping DOCKER_CONTEXT before appending it (os/exec keeps the last duplicate); passing the caller's context to the darwin forceKill; fixing deletion by testing len(status.containers) == 0 alone; removing networks or volumes in the Container fallback (api_containers.md:747-749 limits it to containers); running down when a deleting project's HasMembers is already False (the code skips it on purpose at compose_reconciler.go:288, and the subtest at compose_reconciler_test.go:647 pins that).

Skill improvements ¶
