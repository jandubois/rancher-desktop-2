Design Observations ¶

Concerns ¶

  • The profile repeats what the tool detects (future) Claude Opus 5. config.kiwi binds lima to the raw image and wsl to the tarball, and run detects the format right after it filters (main.go:92, main.go:96-100). Deriving the profile from the format would drop the flag, the Makefile variable (S4), the flag check (S5) and the empty default (S2). But #803 asks for a --profile flag, and a future profile sharing a format would need it back. The lighter step keeps the flag and has run reject a mismatched pair; TestRunProfileAppliesOnlyItsEntries pairs lima with a tarball (main_test.go:252), so it would then need a raw image.
  • Path uniqueness spans profiles (future) Claude Opus 5 Codex GPT 5.6 Sol. Manifest.validate rejects one path in two entries even when their profiles don't overlap; both reviewers' probes got path is already used by entry 0. The rationale at manifest.go:100-102 covers one image receiving both entries, which disjoint profiles rule out. None of the profile-exclusive files #803 lists needs different contents per profile at one path. If one ever does, key the check on path and profile.

Strengths ¶

  • Whole-manifest validation before filtering (in-scope) Claude Opus 5 Codex GPT 5.6 Sol Gemini 3.5 Flash. LoadManifest checks every entry before ForProfile drops any, so a typo in a wsl-only entry fails the macOS build too.
  • One filter point (in-scope) Claude Opus 5. run filters once, before the format dispatch, so neither backend changed.
  • A target-derived profile (in-scope) Codex GPT 5.6 Sol. The overlay runs on the build host, so selecting by runtime.GOOS would pick the host's profile when a Mac builds the Windows image. This answers the first alternative in mook-as's comment on #803.

Review Process Notes ¶

Skill improvements ¶

  • [ ] When a change filters or subsets an input before handing it to existing code, check every rule in that code that derives state from the input, such as ownership, deduplication, or override sets. The subset changes what those rules see, and an item the filter removed can come back through a broader rule the filter never touched, such as a directory copy, a glob, or a default.

Repo context updates ¶

  • [ ] [repo] In the distro overlay manifest, a per-entry profile limit applies to the entry, not the path: a directory-tree entry with a source still writes a profile-excluded path into the other profile's image. When a PR adds profile-limited entries under a directory that a tree entry also copies, check that the tree's source does not hold the same file.
  • [ ] [repo] rdd/go.mod declares Go 1.27, whose composite literals may set a promoted field of an embedded struct directly, and go fix rewrites nested literals into that form. A tool or editor on the Go 1.26 language version rejects it with "requires go1.27 or later". Flag a PR that re-nests such a literal as reverting go fix, and reject any finding that calls the promoted form a compile error.
