Executive Summary ¶

The PR replaces the Windows addPath: manual position rule with a marker file. front and back write ~/.rd<n>/.path-managed, and manual removes the bin directory only while the marker exists. The Go change is sound, and its unit tests pass on macOS and Windows CI. The new BATS file is broken on Windows, though. Two of its three tests fail and the third passes without checking anything. func (r *PathManagementReconciler) writeUserPath(strategy appv1alpha1.AddPathStrategy, forceRemove bool) (bool, error) {
	adding := strategy == appv1alpha1.AddPathFront || strategy == appv1alpha1.AddPathBack

	// Record ownership before the registry write, so a crash in between still
	// leaves the marker for a later manual run to act on.

Review Process Notes ¶

Repo context updates ¶

  • [repo] UPDATE the pkg/rdd-client/gen/ entry: the Lint workflow's Verify generated files job runs make verify-generate, which includes generate-typescript, and fails on any drift. A PR that changes a CRD, a field doc comment included, must commit a regenerated client, so report a missing regeneration against that PR.
  • [repo] On Windows, BATS runs under MSYS2, and paths.bash converts every rdd svc paths value with cygpath -u, so RDD_* paths have the /c/... form. Flag a comparison between an RDD_* path and native Windows output (registry values, powershell.exe or cmd.exe output) unless the path first goes through host_path (cygpath -m).
  • [repo] Windows PowerShell joins every argument after a -Command string into the command text, so $args is empty there. Flag test code that passes data to powershell.exe -Command as trailing arguments; pass it through an environment variable, -File, or a native tool such as reg.exe. [Environment]::GetEnvironmentVariable(..., 'User') also expands REGEXPANDSZ values, and SetEnvironmentVariable writes REG_SZ, so a read-then-write of the user Path through them destroys %VAR% references.
  • [repo] App-group reconcilers that watch with WatchEventLogger run on every App update, status writes included. A test that deletes state that a reconcile recreates under the current spec races those later passes; flag it unless the test first moves the spec to a state that stops recreating it.
