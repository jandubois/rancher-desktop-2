Executive Summary ¶

The PR publishes each Windows tool as a forwarder, a hardlink to one user-owned forwarder copy in ~/.rd<n>/bin beside a .shim file naming the real binary, and reconciles the directory in place on each bundle start. The Go side follows the issue #448 proposal, but nothing builds or packages rdd-forwarder.exe. So a Windows bundle no longer publishes any tool, and the required Windows bats-others check fails. Three doc comments still describe the old behaviour.

// ensureSelfLinks keeps the instance bin directory usable when no application
// bundle has published it. It first prunes symlinks left dangling by an
// uninstalled application, then points the rdd and kubectl links at a standalone
// rdd. Working links and non-symlink entries survive.
func ensureSelfLinks(execPath, binDir, exe string, useSymlink bool) error {
	if err := os.MkdirAll(binDir, 0o755); err != nil {
		return fmt.Errorf("create %q: %w", binDir, err)
	}
	if err := pruneDanglingLinks(binDir); err != nil {
		return err
	}
	// A bundle install publishes Windows forwarders instead of symlinks; prune
	// any whose target an uninstalled application took with it.
	pruneDanglingForwarders(binDir)
	for _, name := range []string{"rdd" + exe, "kubectl" + exe} {
		if err := ensureSelfLink(filepath.Join(binDir, name), execPath, useSymlink); err != nil {
			klog.Warningf("Failed to repair the %q link: %v", name, err)
		}
	}

Acknowledged Limitations ¶

  • .old files can outlive a start. sweepAside skips aside files that are still in use, and the next start removes them.
  • rdd owns the bin directory. One reviewer asked the standalone prune to protect a standalone rdd.exe a user copied into ~/.rd<n>/bin. rdd rewrites that directory on every bundle start, so a future reviewer should not re-suggest guarding user-placed binaries there.
  • shimTarget reads only what rdd writes. Every .shim in the bin directory comes from shimContent, which writes a single path = line, so a key such as path_args never reaches the parser. Do not re-suggest a general key-value parser unless the shims gain more keys.

Review Process Notes ¶

Skill improvements ¶

  • When a change alters what a code path requires (a file it must find, a precondition, a branch one platform takes), find the tests outside the diff that reach that path on every leg of the CI matrix, and check that their fixtures still meet the new requirement. A test the diff does not touch fails as surely as one it does, and the base branch's CI log shows which tests reach the path.

Repo context updates ¶

  • rdd/bats/tests/20-service/7-binlinks.bats builds a fake application bundle and is the only test that reaches the bundle path of binlinks.LinkBundledBinaries; the bats-others leg runs it on macOS, Linux and Windows. A change to what the bundle path expects to find must update that fixture.
  • A packaged bundle's resources/<os>/bin holds executables only, because packaging/electron-builder.yml filters *.tar.gz, *.unsigned and other archives out of resources/; a development tree's copy keeps them. Development builds run rdd/bin/rdd, which binlinks treats as standalone, so the bundle path sees only packaged layouts.
