Executive Summary ¶

The PR builds instance paths in one place: accessors in the instance package, three new rdd svc paths keys for bats and the app, and Lima's filenames constants for the hostagent and serial logs. The Go changes keep every path the same, and their tests pass. One gap needs a fix. No test covers the rewritten guard that stops the app from deleting rdd's live logs. Review Process Notes ¶

Skill improvements ¶

  • Check each assertion in a test a finding proposes against the intended behavior. A test written from what the code does today pins any defect in that behavior, and a reader who applies the patch adopts the defect as a requirement.

Repo context updates ¶

  • [repo] A path that more than one component builds must come from an instance accessor in Go or an rdd svc paths key in bats and the app, even where a hand-built copy is correct today; Lima's file names inside a VM directory come from Lima's filenames constants. A file that one component alone builds and uses stays with that component, and bats builds Lima VM paths as ${RDD_LIMA_HOME}/<vm>/.... Flag a second hand-built copy of a path, and leave a single-owner file alone. The app's RDDPaths interface omits bin_dir on purpose: the merged paths object already has binDir, the bundle's bin directory, and the app does not use the instance bin directory.
