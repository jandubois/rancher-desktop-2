 * Hide the splash window, if it is open, without closing it.  While the splash
 * is the app's only window, closing it would run the window-all-closed handler,
 * which hides the dock icon on macOS.  That also deactivates the app, so a
 * native error box shown next opens while another app stays frontmost.

export function hideSplash() {
  if (splash && !splash.isDestroyed()) {
    splash.off('ready-to-show', showSplash);
    splash.hide();
  }
}

Design Observations ¶

Concerns ¶

  • (in-scope) When a hidden first window's page fails to load, the splash keeps spinning until the user quits (window/index.ts:96-98), and the maintainers haven't ruled on whether that should change. On macOS the dock icon can quit the app. On Windows and Linux the splash is frameless and RD2 doesn't show a tray yet (background.ts:168), so the user can only close the splash, from the taskbar or with Alt+F4. That leaves the app running with no visible window (reasoned, not run). The reviewers raised two alternatives: close the splash, which leaves the screen empty as at the merge-base, or show an error box, which is #463's unfinished half.
