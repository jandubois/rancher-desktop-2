Executive Summary ¶

This PR moves 47 openSUSE guest files and seven .wants links into rdd/overlay/, and lets the raw backend skip a symlink the image already has. Modes, profiles and link targets match config.sh on both the pinned v0.2.8 image and the post-cut images from rancher-desktop-opensuse PR 78. But the Windows Package build, which also builds releases, checks the files out with CRLF, so a released WSL guest cannot run wsl-exec and Lima's boot script never starts.

Design Observations ¶

Concerns ¶

  • (in-scope) Line endings for guest files were protected only by per-workflow git config lines, and the one workflow that builds releases lacks them. A .gitattributes rule covers every checkout, Windows developers' included, and closes C1 as a class. Claude Opus 5.5

Strengths ¶

  • (in-scope) Profiles, modes, owners and .wants targets match config.sh. The overlay applies without error to the v0.2.8 image and to both post-cut images from rancher-desktop-opensuse PR 78. Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.1 Pro Gemini 3.5 Flash
  • (in-scope) The symlink no-op compares targets and still refuses a different one, and both new tests fail against the merge-base image.go. Claude Opus 5.5 Codex GPT 6 Astra Gemini 3.1 Pro Gemini 3.5 Flash

Review Process Notes ¶

Skill improvements ¶

  • When a change adds files that a build copies byte for byte into a shipped artifact, compare how the test workflow and the release workflow check them out and build them. Line-ending conversion, symlink handling and file modes can differ between the two, and a green test run proves only the test workflow's checkout. When the PR's own CI uploaded the release artifact, inspect it.

Repo context updates ¶

  • [repo] Everything under rdd/overlay/ reaches the guest byte for byte. The Package workflow, which also builds releases on tags, checks out on windows-latest with Git for Windows' default core.autocrlf=true, while the BATS and lint workflows set core.autocrlf false, so BATS cannot see a line-ending defect in a shipped guest file. Check that a new text file bound for the guest falls under an eol=lf rule in .gitattributes; to confirm, extract the distro embedded in the PR's rdd.windows.x86_64.exe artifact.
  • [repo] The rancher-desktop-opensuse reverse test builds RD2 main, never the RD2 PR a paired openSUSE change depends on. To check such a pair, apply the RD2 manifest with distro-overlay to the images the openSUSE PR's Build run uploaded (distro-raw.xz-<arch>, distro-tar.xz-<arch>), once per profile.
